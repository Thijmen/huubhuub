The Android app now ships through Google Play: each release uploads a new build to the internal testing track when the app's native code changed, and an over-the-air update otherwise. The app's version now follows the bot's, and the in-app "download the new APK" prompt is gone. The app id is now `dev.thijmen.apps.huubhuub`, so it installs as a new app next to the old APK.
