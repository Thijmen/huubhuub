The phone app keeps itself up to date. Over-the-air updates download in the background and start the next time the app is opened after a few minutes away. When an update needs a new APK, the app offers the download instead of silently falling behind. Each APK now stays available on the "app-android" GitHub release, which is also where the invite page's "download the app" link goes by default (`APP_DOWNLOAD_URL`).
